Optimize images on your desktop

With Squoosh's engines: WebP, AVIF, JPEG XL, MozJPEG, OxiPNG and QOI. The same file as the official tools, and you see the result right away.

Compress while seeing what you lose

You compare the original and the compressed image with a slider, see how much it weighs and where quality is lost, and adjust until you're happy.

  • WebP
  • AVIF
  • JPEG XL
  • MozJPEG
  • PNG (OxiPNG)
  • QOI

The same file as the official tools

cwebp, cjpeg, oxipng, avifenc and cjxl are built into Apolo and produce the same file, byte for byte. You use all their options while you watch, and copy the equivalent command.

Quality measured, not guessed

SSIMULACRA 2, PSNR and SSIM, a map of where detail is lost, and quality by score: Apolo finds the lowest quality that can't be told apart from the original.

Studio and batches

You fine-tune one image, save the setting as a preset and apply it to whole folders, with their subfolders and without overwriting anything.

Crop, resize and reduce the palette

Like in Squoosh, and in any format: cropping with the mouse, with aspect ratios.

Opens iPhone photos

HEIC, as well as PNG, JPEG, WebP, AVIF, JPEG XL, TIFF, GIF, BMP, QOI and PNM, and auto-rotates them by their orientation.

Native, light and offline

Your images never leave your computer. With 24-megapixel photos it stays around 2 GB of memory, even in batches of hundreds: it fits on an 8 GB Mac.

Where it's lost, in plain sight

Differences mode paints where the result drifts from the original. With the SSIMULACRA 2 score, the same one libjxl's tool gives, you know whether it will show before you publish.

  • 90 or more: can't be told apart from the original.
  • 80: can't be told apart side by side.
  • 70: high quality. 50: it shows.

Whole folders

Drop a folder on Batches and it converts it in parallel, to one or more formats, with a preset or aiming for a score.

  • It keeps the subfolders and never overwrites: if a name exists, photo-2.webp.
  • “Only the lightest”: for each image, the format that weighs least.
  • When it's done, how much was saved and which ones came out worse.

With an AI agent

From Claude, Cursor, VS Code or any agent that speaks MCP: it analyzes, optimizes, compares formats at the same quality, measures, crops and converts folders, with Apolo's engines and on your computer. It never overwrites or deletes.

The server comes with the app and updates with it. In Apolo, the MCP row has what to copy for each agent and the Claude Desktop extension. In Claude Code:

# macOS
claude mcp add --scope user apolo -- "/Applications/Apolo.app/Contents/MacOS/apolo-mcp"
# Windows
claude mcp add --scope user apolo -- "%LOCALAPPDATA%\Apolo\apolo-mcp.exe"
# Linux (.deb, .rpm and AUR)
claude mcp add --scope user apolo -- /usr/bin/apolo-mcp

Command line

apolo does the same as the window, with the same presets, for your scripts. apolo webp, jpeg and png take the options of cwebp, cjpeg and oxipng; apolo avif and jxl are avifenc and cjxl.

# With Homebrew, on macOS and Linux
brew install webcafeina/apolo/apolo

apolo webp -q 80 photo.jpg -o photo.webp
apolo avif -q 60 photo.png photo.avif
apolo lote photos/ --formato webp,avif --mas-ligero
apolo medir photo.png photo.webp

Also in the downloads, without Homebrew. It speaks your system's language; force English with --idioma en.

macOS, the first time

Apolo isn't signed: open it and, in System Settings › Privacy & Security, click “Open Anyway”. If it says it's damaged: xattr -dr com.apple.quarantine /Applications/Apolo.app. Or with Homebrew: brew install --cask webcafeina/apolo/apolo.

Windows, the first time

SmartScreen warns because it isn't signed: “More info” › “Run anyway”.

Linux

Best with your package manager (below). Otherwise, the package on its own: sudo apt install ./Apolo_X.Y.Z_amd64.deb or sudo dnf install ./Apolo-X.Y.Z-1.x86_64.rpm. The AppImage works on any distribution: chmod +x and open it.

Linux, with your package manager

Apolo installs and updates with your system's. The repositories are signed with Apolo's key.

# Debian and Ubuntu
sudo install -dm755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/apolo.asc https://apolo.webcafeina.com/apolo.asc
sudo curl -fsSLo /etc/apt/sources.list.d/apolo.sources https://apolo.webcafeina.com/apt/apolo.sources
sudo apt update && sudo apt install apolo

# Fedora
sudo curl -fsSLo /etc/yum.repos.d/apolo.repo https://apolo.webcafeina.com/rpm/apolo.repo
sudo dnf install apolo

# openSUSE
sudo zypper addrepo https://apolo.webcafeina.com/rpm/apolo.repo
sudo zypper install apolo

# Arch, Manjaro, EndeavourOS, CachyOS (AUR)
yay -S apolo-bin

All versions on GitHub, with SHA256SUMS.txt to check every file.
