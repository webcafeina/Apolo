El mismo fichero que las herramientas oficiales

cwebp, cjpeg, oxipng, avifenc y cjxl van dentro de Apolo y dan el mismo fichero, byte a byte. Usas todas sus opciones viéndolas, y copias la orden equivalente.

Calidad medida, no a ojo

SSIMULACRA 2, PSNR y SSIM, un mapa de dónde se pierde detalle y la calidad por nota: Apolo busca la más baja que no se distingue del original.

Estudio y lotes

Afinas una imagen, guardas el ajuste como preset y lo aplicas a carpetas enteras, con sus subcarpetas y sin sobrescribir nada.

Recortar, redimensionar y reducir la paleta

Como en Squoosh, y en cualquier formato: el recorte, con el ratón y con proporciones.

Abre las fotos del iPhone

HEIC, además de PNG, JPEG, WebP, AVIF, JPEG XL, TIFF, GIF, BMP, QOI y PNM, y las endereza según su orientación.

Nativo, ligero y sin conexión

Tus imágenes no salen de tu ordenador. Con fotos de 24 megapíxeles se queda en unos 2 GB de memoria, también en lotes de cientos: cabe en un Mac de 8 GB.

Dónde se pierde, a la vista

El modo Diferencias pinta dónde se aleja el resultado del original. Con la nota SSIMULACRA 2, la misma que da la herramienta de libjxl, sabes si se va a notar antes de publicarlo.

  • 90 o más: no se distingue del original.
  • 80: no se distingue puestas una al lado de otra.
  • 70: alta calidad. 50: se nota.

Carpetas enteras

Sueltas una carpeta en Lotes y la convierte en paralelo, a uno o varios formatos, con un preset o buscando una nota.

  • Repite las subcarpetas y nunca sobrescribe: si un nombre existe, foto-2.webp.
  • «Solo el más ligero»: de cada imagen, el formato que menos pesa.
  • Al acabar, cuánto se ahorró y cuáles salieron peor.

Con un agente de IA

Desde Claude, Cursor, VS Code o cualquier agente que hable MCP: analiza, optimiza, compara formatos a la misma calidad, mide, recorta y convierte carpetas, con los motores de Apolo y en tu ordenador. Nunca sobrescribe ni borra.

El servidor va dentro de la aplicación y se actualiza con ella. En Apolo, la fila MCP tiene lo que hay que copiar para cada agente y la extensión de Claude Desktop. En Claude Code:

# macOS
claude mcp add --scope user apolo -- "/Applications/Apolo.app/Contents/MacOS/apolo-mcp"
# Windows
claude mcp add --scope user apolo -- "%LOCALAPPDATA%\Apolo\apolo-mcp.exe"
# Linux (.deb, .rpm y AUR)
claude mcp add --scope user apolo -- /usr/bin/apolo-mcp

Línea de órdenes

apolo hace lo mismo que la ventana, con los mismos presets, para tus scripts. apolo webp, jpeg y png aceptan las opciones de cwebp, cjpeg y oxipng; apolo avif y jxl son avifenc y cjxl.

# Con Homebrew, en macOS y Linux
brew install webcafeina/apolo/apolo

apolo webp -q 80 foto.jpg -o foto.webp
apolo avif -q 60 foto.png foto.avif
apolo lote fotos/ --formato webp,avif --mas-ligero
apolo medir foto.png foto.webp

macOS, la primera vez

Apolo no está firmada: ábrela y, en Ajustes del Sistema › Privacidad y seguridad, pulsa «Abrir igualmente». Si dice que está dañada: xattr -dr com.apple.quarantine /Applications/Apolo.app. O con Homebrew: brew install --cask webcafeina/apolo/apolo.

Windows, la primera vez

SmartScreen avisa porque no está firmada: «Más información» › «Ejecutar de todos modos».

Linux

Mejor con tu gestor de paquetes (abajo). Si no, el paquete suelto: sudo apt install ./Apolo_X.Y.Z_amd64.deb o sudo dnf install ./Apolo-X.Y.Z-1.x86_64.rpm. La AppImage vale para cualquier distribución: chmod +x y abrirla.

Linux, con tu gestor de paquetes

Apolo se instala y se actualiza con los de tu sistema. Los repositorios están firmados con la clave de Apolo.

# Debian y Ubuntu
sudo install -dm755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/apolo.asc https://apolo.webcafeina.com/apolo.asc
sudo curl -fsSLo /etc/apt/sources.list.d/apolo.sources https://apolo.webcafeina.com/apt/apolo.sources
sudo apt update && sudo apt install apolo

# Fedora
sudo curl -fsSLo /etc/yum.repos.d/apolo.repo https://apolo.webcafeina.com/rpm/apolo.repo
sudo dnf install apolo

# openSUSE
sudo zypper addrepo https://apolo.webcafeina.com/rpm/apolo.repo
sudo zypper install apolo

# Arch, Manjaro, EndeavourOS, CachyOS (AUR)
yay -S apolo-bin
